# view 展示优化与批量审核

默认展示名称、状态、判断条件和主要操作。技术编号、长表达式、公式、原文依据及模型版本通过折叠入口查看。规则条件使用分组表格，“全部满足”和“任意一项满足”在组标题标明。审核页继续直接编辑。

规则文档点击“批量审核”，勾选当前文档条目，可选审核意见，再点击“审核并生效所选 N 条”。已完整生效和已标记停用条目不可选。有校验问题的所选条目需要修正或取消勾选。先保存未保存修改，再进行批量审核。

所选条目全部校验通过后，在一次事务中逐条记录完整审核快照，再统一构建索引并发布。不会带出其他条目或其他文档草稿。任务中保留所选规则清单，刷新后仍可查看进度。索引失败保留审核结果，点击“重试本批 N 条”复用审核并重试；条目修改后需重新核对。批量提交后页面定位首个所选条目，展示本批进度。

## 管理接口

新增 `POST /api/v1/admin/documents/{id}/confirm-batch`，使用管理令牌。

```json
{"expected_version": 2, "rule_ids": ["rule-a", "rule-b"], "note": "已核对"}
```

`rule_ids` 为1至100条不重复的当前文档规则编号。`note` 可省略。返回202与 `task_id`、确认后的 `edit_version` 及 `rule_ids`，使用原任务接口查看发布结果。版本冲突返回409，校验问题返回400，整批审核不生效。索引失败则任务为failed，已审核快照保留。

旧数据库启动时新增批量任务关联表。旧的单条任务及 Agent 公开读取接口继续使用原约定。
