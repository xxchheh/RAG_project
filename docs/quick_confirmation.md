# 知识管理双工作区

## 页面入口

“知识管理”下分“参考资料”和“规则文档”，采用左侧文档列表、右侧当前文档的工作区。点击文档直接切换右侧内容，不再跳到独立审核页。上传默认采用所在栏目类型，替换沿用原类型；误分类通过“文档更多 → 重新解析并调整类型”修正。

“知识问答”和“专业规则”继续用于已发布知识的问答和规则目录浏览，后者不是规则文档审核入口。

文档列表保留搜索与处理状态。知识库、栏目、当前文档、规则及参考资料页码会在当前浏览器会话中记忆。窄屏通过“选择文档”打开文档列表。切换时若有编辑，选择保存并切换、放弃修改或取消。

## 规则文档

顶部只有一套条目选择器和上一条／下一条。保存、审核通过并生效、核对来源始终位于顶部固定栏，长文档不必滚到底部操作。

页面主体为名称、设备、原文判据、结构化条件及单位。现象、原因、措施和审核说明收在当前条目的折叠区域。“核对来源”打开抽屉，需要时可调整关联原文。新增、退回和标记停用位于“更多”。

“审核通过并生效”一次确认当前条目的说明和判断条件，自动准备索引和发布；不会批准整篇文档或其他条目。内容或依赖的来源被修改后，仅相关审核失效；未保存编辑须先保存，校验错误须先修正。

## 参考资料

先看简洁摘要，再按需抽查。无需逐页确认，随时可点击顶部“确认整份入库”。

PDF提供原页预览，支持输入物理页码、上一页／下一页；展开“对照本页识别文本”可以核对和修正提取内容。需关注页可点击定位，排除页可选填如 `12, 15-18`。原文件、解析结果及历史版本保留。

Word和Markdown按标题、段落组织；PPTX按幻灯片展示提取文字和已有图片，不提供完整幻灯片原页渲染。不支持原页渲染时可以下载原件核对，不会展示无效PDF按钮。

未审核规则、待核对公式、未识别图像页、解析器排除内容及人工排除页不会进入说明检索。修正文字不会自动将待核对内容提升为说明；需要明确调整内容处理并确认。参考资料允许抽查后整份确认，不表示逐字校对，也不会自动转成诊断规则。

## 任务、历史与升级

当前文档或条目显示解析中、待确认、入库中、失败和已生效等状态。处理任务关联文档修订版与条目，刷新后可恢复进度或失败信息。确认与发布是两步内部操作，只有索引准备和版本切换成功才生效。失败保留审核结果和原发布版，可原位重试；相同内容不会重复增加审核记录。

“知识库更多 → 历史记录与恢复”查看发布变更或恢复历史；恢复会创建新版本并重置现有草稿审核。高级维护保留全库批量发布，日常无需使用。

停止服务，更新源码，按原命令启动并刷新浏览器即可。任务关联和审核快照表自动创建，既有数据库、原件、审核和发布记录保留。旧发布版不改写，不要求重新解析或重新审核。此前仅确认判据的规则仍保留原发布状态，进入新工作区后可进一步审核完整条目。

## 管理接口兼容扩展

所有管理接口需要管理令牌。Agent公开接口及规则格式不变。

`POST /api/v1/admin/documents/{id}/confirm`：

```json
{"expected_version": 2, "target": "rule", "rule_id": "规则编号", "include_context": true}
```

- 新增可选 `include_context`，默认 `false` 保持原来的独立规则审核行为；新规则工作区传 `true`，审核当前完整条目及关联来源快照。
- 说明确认仍传 `target=description`，可选 `excluded_pages`；不能同时使用 `include_context=true`。
- 返回202、`task_id`及审核后的`edit_version`，202不等于已生效。既有任务接口继续可用。
- `PATCH /api/v1/admin/documents/{id}` 新增可选 `excluded_pages`，支持保存参考资料的排除设置。原确认接口直接传排除页的方式也保留。
- 管理端文档列表及详情增加关联 `tasks`，`publication.rules` 提供条目生效状态。完整条目的审核字段与关联原文快照独立留存，可在“文档更多 → 审核记录”展开查看；内部审核标记不添加为Agent字段。
- 单文档发布、原独立审核、全库发布、恢复及重建接口保留，现有调用无需改动。
