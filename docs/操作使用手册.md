# 专业知识库操作使用手册

适用于当前 main 分支，面向知识维护人员和日常查询用户。

## 1. 进入系统与选择知识库

1. 浏览器打开管理员提供的服务地址。
2. 点击左下角“连接设置”，填写访问令牌，选择“管理与审核”或“只读查询”，点击“连接”。
3. 在页面顶部选择当前知识库。需要新增时，使用“知识库更多 → 创建知识库”。

管理模式用于上传、修改和审核；只读模式用于查询知识和浏览专业规则。令牌仅保存在当前浏览器会话中，请勿分享或放入截图。

> 【截图 1】系统首页，展示四个导航入口与顶部知识库选择区域。

## 2. 参考资料入库

适合教材、书籍、课件等说明性资料，支持 Markdown、Word、PDF 和 PPTX。

1. 进入“参考资料”，点击“上传参考资料”，选择文件并上传解析。
2. 在左侧选择文档，查看解析状态和“资料概况”。长文档需要等待处理完成。
3. 在“原页核对”中抽查内容，按需展开“对照识别文本”。PDF 可输入物理页码跳转；PPTX 展示提取文字和已有图片。
4. 关注系统提示的异常页面，必要时下载原件核对。可在“按页排除”中填写 `12, 15-18` 等范围。
5. 有修改时先保存，然后点击“确认整份入库”，等待显示已生效。

参考资料按整份确认，无需逐页点击通过。待核对公式、未识别图像页等内容不会自动进入公共检索，整份确认后仍应留意这些提示。

## 3. 规则文档审核

适合包含设备故障、现象、原因、处理措施及明确判断条件的机理规则文档。

### 单条审核

1. 进入“规则文档”，上传文件，等待解析完成。
2. 在左侧选择文档，通过“当前规则”或上一条、下一条切换条目。
3. 核对名称、适用设备、原文判据及结构化条件，并展开查看现象、原因和措施。
4. 重点检查指标、单位、阈值、比较符及条件组关系。“全部满足”表示且，“任一满足”表示或。
5. 需要对照原文时点击“核对来源”。修改后先“保存修改”，再点击“审核通过并生效”。

审核范围是当前完整条目及关联来源。只有入库任务成功后，条目才进入已发布知识范围。

> 【截图 3】规则审核工作区，展示条目选择、原文判据、条件编辑及主要操作。

### 批量审核

同一文档中多条规则核对完成后，可以统一审核。

1. 保存当前修改，点击“批量审核”。
2. 勾选需要审核的条目，或全选可处理条目。
3. 确认名称、状态和判据摘要，按需填写审核意见。
4. 点击“审核并生效所选 N 条”，等待任务完成。

已完整生效和已标记停用的条目不可选。所选条目必须全部通过校验，存在问题时先修正或取消勾选。索引失败会保留审核结果，可使用“重试本批 N 条”。

## 4. 知识问答与依据查看

1. 进入“知识问答”，输入问题，例如“电机轴承润滑不足有哪些原因和处理措施？”。
2. 点击“生成回答”。系统检索已发布知识，再由大模型根据证据组织回答并附引用。
3. 展开引用查看原文及来源；需要单独检查检索结果时，点击“查看检索依据”。
4. 按需展开查询范围，选择设备类型、发布版本和检索条数。一般原理问题可保留所有设备类型。

回答需要服务端已配置可用的大模型。知识不足或模型调用失败时，页面会提示原因。专业结论应结合引用核对。

## 5. 专业规则查阅

1. 进入“专业规则”，按设备类型或故障关键词筛选。
2. 在左侧故障目录选择条目。
3. 查看判断条件、机理现象、可能原因和处理措施。
4. 需要深入核对时，展开完整表达式、计算说明、原文依据或技术详情。

该页面只读浏览已审核生效的规则。修改请回到“规则文档”。系统提供完整适用规则，设备取数、数值判断和诊断报告由外部 Agent 负责。

## 6. 文档更新与历史记录

- **替换文件**：选中文档，在“文档更多”中点击“替换文件”。新修订版解析后需重新核对确认。
- **重新解析**：使用“重新解析并调整类型”，适合处理类型选择错误或需要重新提取内容的情况。
- **停用文档**：在“文档更多”中点击“停用文档”，等待生效后退出当前发布范围，历史记录保留。
- **查看历史**：使用“知识库更多 → 历史记录与恢复”，查看发布记录、版本详情及变更。恢复历史内容会生成新版本，操作前应确认范围。

更新确认前继续使用原发布内容。日常审核确认会自动完成发布，通常无需额外操作发布页面。

## 7. 常见使用提示

- **审核通过后暂时查不到**：检查入库或索引任务是否完成，审核通过与已生效是两个状态。
- **解析或入库失败**：查看当前文档的失败提示，处理原因后使用对应重试入口。
- **扫描件或公式识别有误**：对照原页核对，修正可编辑内容或排除相关页面，保留待核对提示。
- **切换页面提示未保存**：选择保存并切换、放弃修改或取消。
- **更新系统后样式未变化**：强制刷新浏览器，必要时关闭旧页面后重新打开。
